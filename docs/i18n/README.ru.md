Лёгкая панель мониторинга, круглосуточного поддержания активности (Keep-awake) и удалённого управления облачными ВМ **instabox.sh** для нескольких аккаунтов на базе Go и MCP.

## Возможности

- **Один лёгкий бинарный файл Go** (`CGO_ENABLED=0`, встроенный веб-интерфейс через `embed.FS`, встроенная SQLite `modernc.org/sqlite`).
- **Первичная настройка администратора**: регистрация блокируется после создания первого администратора (`scrypt`, cookie `HttpOnly`, защита CSRF и Fetch Metadata).
- **Несколько аккаунтов и создание ВМ в 2 вкладках**: привязка API-ключей `ibk_...` с шифрованием AES-256-GCM и создание новых ВМ с выбором доступного аккаунта, шаблона/снимка, ресурсов и лимитов.
- **Переименование, подтверждённое удаление и режимы Сетка/Карточки**: цветовые индикаторы статуса (корректная обработка `runtime.ready=false` после пробуждения), выровненная карточка для широких экранов, быстрое переименование и диалог подтверждения удаления.
- **Режим «Не засыпать» (`keepalive`) для каждой ВМ**: автоматическое продление аренды `ibmon-keepalive` (3600 с), пробуждение после автосна, превентивный перезапуск до лимита 8 ч / `maxRunMinutes` и уважение ручной остановки.
- **4 SVG-кнопки управления с подсказками при наведении**: разбудить, приостановить, запустить и немедленно остановить через официальный API `instabox.sh`.
- **Таймер работы в реальном времени и графики в стиле Beszel**: отсчёт по `runStartedAt`, статистика за месяц, графики ЦП, ОЗУ, Диска (`/` и `/data`), Сети и Диска I/O (опрос каждые 30 сек, история за 24 ч, хранение 7 дней).
- **Сервисные API-ключи (`ibmon_*`) и удалённый MCP (`/mcp`)**: создание и отзыв Bearer-токенов с хэшем SHA-256 в **Меню → API-ключи и MCP**, чтобы Hermes Agent или скрипты могли управлять всеми ВМ через 12 MCP-инструментов и REST API без раскрытия ключей `ibk_*`. Удаление ВМ через API/MCP требует одноразового токена подтверждения (срок действия 5 минут).
- **PWA и 11 языков**: шрифт Google Sans, светлая/тёмная/системная тема, иконки и веб-манифест.

## Быстрый запуск (Docker)

```bash
docker compose up -d --build
```
